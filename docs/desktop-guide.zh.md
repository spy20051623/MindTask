# 桌面端指南

MindTask 是桌面优先的任务管理器。PySide6 桌面 UI 是日常使用的主要入口；CLI 命令主要用于脚本和调试。

桌面端直接调用 `MindTaskDB` 核心，不会通过 CLI 转发操作。

## 运行

安装 UI 依赖：

```bash
pip install -e .[ui]
```

启动桌面端：

```bash
python MindTask_ui.py
```

桌面端按这个顺序选择配置文件：软件目录旁的 `config/mindtask.ini`，然后是 `%APPDATA%\MindTask\mindtask.ini`。首次启动时，如果两者都不存在，MindTask 会打开欢迎设置窗口。设置流程会要求选择语言、配置文件创建位置，然后选择打开已有数据库或创建新数据库。只有设置完成后才会进入主窗口。如果模板缺失，启动会给出明确错误。

如果当前配置存在，但其中的数据库文件不存在或不可用，MindTask 不会静默创建新数据库，而是打开数据库选择窗口，由用户选择已有数据库或明确新建数据库。

## 布局

桌面端采用紧凑页面、底部导航和右侧抽屉。

主要页面：

- 任务
- 设置

任务页是主要工作区：

- 左侧：即将到期筛选和项目导航
- 中间：可搜索的任务表格
- 右侧：选中任务或新建任务时显示任务详情抽屉

即将到期筛选包括今天、明天、三天和一周。每个到期筛选都会包含已超期且未完成的任务。

离开任务页时，任务页抽屉会关闭。如果任务详情抽屉里有未保存修改，MindTask 会在丢弃前询问确认。返回任务页时会刷新任务列表。

状态栏会持续显示当前页面的数量，例如任务数、项目数或历史记录数。对于保存、创建、删除、切换数据库、备份数据库、回退历史等不一定能从界面变化直接看出结果的操作，状态栏也会显示操作结果。

## 任务

任务表格支持搜索、项目筛选、到期筛选和表头排序。搜索属于任务页；如果当前处于搜索结果中，即使手动清空搜索框，清除搜索的操作仍然可用。

默认启用智能排序。未完成任务显示在已完成任务之前。未完成任务按截止日期、优先级排序；已完成任务按完成时间排序。当智能规则无法区分两条任务时，会使用当前表头排序，最后用 ID 保持稳定顺序。

设置页提供隐藏已完成任务的选项。

## 任务详情

新建和编辑任务都在任务详情抽屉中完成。

可编辑字段：

- 标题
- 详情
- 状态
- 优先级
- 项目
- 截止时间

详情字段使用 Markdown。MindTask 默认显示渲染后的 Markdown；进入编辑模式需要显式操作。`Esc` 会先退出 Markdown 编辑，再关闭抽屉。

任务详情修改会先保留为草稿，直到用户保存。如果用户在草稿已修改时尝试关闭、刷新、切换任务、切换筛选或打开另一个任务页抽屉，MindTask 会询问确认，除非该操作本身就是明确的取消或放弃修改。

## 检查单

检查项从任务详情 Markdown 中解析，并显示在渲染详情下方，标签为 `同步自任务详情`。

支持的 Markdown 检查项格式：

```text
- [ ] 未完成检查项
- [x] 已完成检查项
```

检查单操作会更新 Markdown 草稿：

- 在检查单行中切换完成状态
- 从检查单工具栏新增检查项
- 二次确认后删除检查项
- 直接在检查单区域编辑检查项名称

检查单修改只有在保存任务后才会写入数据库。如果用户完成任务时当前草稿仍有未完成检查项，MindTask 会询问是继续完成、完成全部检查项并保存，还是取消。

## 截止日期

截止日期使用与其他接口相同的核心存储格式：

```text
YYYY-MM-DD HH:MM:SS
```

UI 提供三种模式：

- 无截止日期
- 全天
- 精确时间

聚焦或编辑日期会切换到全天模式。聚焦或编辑时间会切换到精确时间模式。时间建议以半小时为间隔，同时仍允许手动输入更精确的时间。

全天任务会以 `due_mode = all_day` 存储，`due_date` 为所选日期的 `00:00:00`。

## 项目和历史

项目管理以右侧抽屉形式在任务页中打开。它支持创建、重命名和删除项目。仍包含任务的项目不能在 UI 中删除。

选中任务的最近历史显示在任务详情抽屉内。全局操作历史从任务页以右侧抽屉打开。回退操作需要确认。回退选中的历史记录时，会从最新记录一直回退到该记录。

## 设置

设置页包括：

- 通用设置：主题、语言、智能任务排序、隐藏已完成任务
- 数据设置：当前数据库、重新加载、备份、切换已有数据库、创建新数据库
- 快捷键
- 关于：应用版本、配置文件路径、当前数据库路径

主题设置保存在 `ui.theme`。语言设置保存在 `ui.language`。

数据库设置会在切换或创建数据库前校验文件路径：

- 路径必须是绝对路径。
- 文件后缀必须是 `.db`、`.sqlite` 或 `.sqlite3`。
- 已有数据库必须是合法 SQLite 文件。
- 已有数据库必须包含 MindTask schema。
- 在已有合法后缀文件上创建数据库时，会在覆盖前询问确认。

数据库设置错误会以设置页内联红色警示显示，而不是弹出警告框。

## 快捷键

当 MindTask 窗口获得焦点时，快捷键生效。快捷键可以在设置页修改，并保存在配置文件的 `[shortcuts]` 下。

快捷键行会显示聚焦、已修改、重复和非法状态。每一行都可以恢复为已保存值或重置为默认值。鼠标点击只会聚焦快捷键字段；快捷键录入使用键盘输入。

单键快捷键仅允许 `Esc` 和 `F1` 到 `F12`；其他按键需要搭配 `Ctrl`、`Alt` 或 `Meta`。

默认快捷键：

- `Ctrl+1`：打开任务页
- `Ctrl+2`：打开设置页
- `Ctrl+P`：打开或关闭项目管理
- `Ctrl+N`：在任务页新建任务
- `Ctrl+F`：在任务页聚焦搜索框
- `Esc`：先退出局部编辑，再关闭任务详情；如果详情已关闭，则清除当前搜索
- `F5`：刷新数据
- `Ctrl+H`：打开操作历史；如果任务页历史已打开，则关闭它
- `Ctrl+S`：保存当前任务详情
- `Ctrl+Enter`：完成当前任务
- `Ctrl+R`：确认后删除当前任务
- `Ctrl+Left`：在分页任务/历史列表中跳到上一页
- `Ctrl+Right`：在分页任务/历史列表中跳到下一页

## 维护说明

UI 代码按职责分组：

- `src/ui/tasks`：任务页、任务抽屉、任务详情辅助逻辑、检查单、截止日期编辑器、项目
- `src/ui/settings`：设置页、数据库设置、快捷键设置、开关控件
- `src/ui/shared`：共享样式、图标、i18n、警示、状态栏、常量和对话框辅助函数

面向用户的固定文案应通过 `src/ui/shared/i18n.py` 本地化。

修改 UI 后，应运行 Python 编译检查，并在不需要完整交互运行时使用聚焦的 offscreen Qt 烟测。

## Windows 打包

Windows 构建脚本会创建便携桌面端包：

```powershell
.\scripts\build_windows.ps1
```

脚本会构建 `dist\MindTask\MindTask.exe`，并在 `dist\` 下创建带版本号的 zip 文件。便携应用目录和 zip 包中，`README.md`、`README.zh.md` 与 `docs` 会放在 `MindTask.exe` 同级。

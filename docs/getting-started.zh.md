# 新手入门

这份指南面向第一次使用 MindTask 桌面端的用户。它会带你完成打开软件、首次设置、创建第一条任务、使用 Markdown 详情和检查单，以及找到最重要的设置项。

## 1. 安装并打开 MindTask

安装桌面端依赖：

```bash
pip install -e .[ui]
```

打开应用：

```bash
python MindTask_ui.py
```

MindTask 会把当前配置保存在 `config/mindtask.ini`。如果这个文件不存在，MindTask 会从 `config/mindtask.ini.template` 创建配置，并打开欢迎设置窗口。

## 2. 完成首次设置

欢迎设置需要做两个选择：

1. 选择语言。
2. 选择数据库。

新用户建议选择 **新建数据库**。请选择一个绝对路径，文件名需要以 `.db`、`.sqlite` 或 `.sqlite3` 结尾。

路径示例：

```text
C:\Users\you\Documents\MindTask\mindtask.db
C:\Users\you\Documents\MindTask\personal-tasks.sqlite3
```

如果你已经有 MindTask 数据库，请选择 **使用现有数据库**，然后选择已有数据库文件。

设置成功后会进入主窗口。

## 3. 认识主窗口

MindTask 默认打开任务页。

任务页有三个主要区域：

- **左侧**：即将到期筛选和项目筛选
- **中间**：任务表格
- **右侧**：创建或选中任务时显示的任务详情抽屉

底部导航可以在 **任务** 和 **设置** 之间切换。

底部状态栏会持续显示当前页面的数量，例如当前显示了多少条任务。保存、创建、删除、备份数据库、回退历史等操作完成后，也会在这里显示结果。

## 4. 创建第一条任务

在任务页按 `Ctrl+N`，或点击新建任务按钮。

在任务详情抽屉里：

1. 输入标题，例如 `Plan the week`。
2. 填写详情，例如备注或简单计划。
3. 如有需要，选择优先级。
4. 如有需要，选择项目。
5. 如有截止时间，设置截止日期。
6. 点击 **创建**。

创建成功后，任务会出现在任务表格里。

## 5. 添加 Markdown 详情

任务详情支持 Markdown。你可以写普通文本，也可以使用简单的 Markdown 格式：

```markdown
Prepare the weekly plan.

## Focus

- Review unfinished tasks
- Pick the top priorities
- Check calendar conflicts
```

MindTask 默认显示渲染后的 Markdown。只有需要修改详情时，再进入编辑模式。

按 `Esc` 会先退出 Markdown 编辑，再关闭任务抽屉。

## 6. 使用检查单

检查项写在任务详情的 Markdown 里：

```markdown
- [ ] Review unfinished tasks
- [ ] Pick top priorities
- [x] Clean up old notes
```

MindTask 会读取这些行，并在详情下方显示检查单区域。

你可以在检查单区域：

- 标记检查项完成
- 新增检查项
- 二次确认后删除检查项
- 双击检查项名称进行编辑

检查单操作会修改任务详情草稿。只有点击 **保存** 后，变更才会写入数据库。

如果任务还有未完成检查项，而你尝试完成任务，MindTask 会询问接下来怎么处理：仅完成任务、完成全部检查项并保存，或取消。

## 7. 设置截止日期

任务抽屉有三种截止日期模式：

- **无截止日期**：任务没有截止时间。
- **全天**：任务在某一天截止，但没有具体时间。
- **精确时间**：任务在某个日期的某个时间截止。

聚焦或编辑日期会切换到全天模式。聚焦或编辑时间会切换到精确时间模式。

左侧即将到期筛选可以快速查看今天、明天、三天内或一周内到期的任务。已超期且未完成的任务也会包含在这些筛选里。

## 8. 用项目整理任务

项目在任务页中管理。

按 `Ctrl+P`，或点击任务侧边栏里的项目管理按钮，可以打开项目管理抽屉。

你可以：

- 创建项目，例如 `Work`、`Personal` 或 `Reading`
- 重命名项目
- 删除空项目

仍然包含任务的项目不能在 UI 中删除。请先移动或删除其中的任务。

## 9. 搜索、排序和筛选

使用任务页的搜索框按文本查找任务。

使用项目筛选查看某个项目下的任务。

使用到期筛选聚焦近期任务。

默认情况下，智能排序会把未完成任务放在已完成任务前面，并按截止日期和优先级排列未完成任务。你仍然可以点击表头排序；当智能排序无法区分两条任务时，会使用当前表头排序作为补充。

## 10. 保存、完成或删除任务

编辑任务时：

- 点击 **保存** 保存草稿。
- 点击完成按钮，或按 `Ctrl+Enter` 完成任务。
- 点击删除按钮，或按 `Ctrl+R`，确认后删除任务。

如果任务已经被修改，而你尝试切换到别处，MindTask 会在丢弃未保存修改前询问确认。

## 11. 从历史中回退

MindTask 会记录写入操作历史。

在任务页按 `Ctrl+H` 可以打开全局历史。

你可以回退最新操作，也可以从最新操作一直回退到选中的某条历史记录。回退前会要求确认。

选中任务的最近历史也会显示在任务详情抽屉中。

## 12. 调整设置

从底部导航打开设置页。

通用设置：

- 主题
- 语言
- 智能任务排序
- 隐藏已完成任务

数据设置：

- 重新加载当前数据库
- 备份当前数据库
- 切换到另一个已有 MindTask 数据库
- 创建新数据库

快捷键设置：

- 编辑快捷键
- 恢复已保存的快捷键
- 重置为默认快捷键

数据库路径必须是绝对路径，并且必须以 `.db`、`.sqlite` 或 `.sqlite3` 结尾。已有数据库必须是合法的 MindTask SQLite 数据库。如果你在已有路径上创建新数据库，MindTask 会在覆盖前询问确认。

## 13. 推荐的第一次练习

可以按下面的小流程熟悉主要功能：

1. 创建一个名为 `Personal` 的项目。
2. 创建一个名为 `Plan the week` 的任务。
3. 添加这些详情：

   ```markdown
   Prepare a simple weekly plan.

   - [ ] Review unfinished tasks
   - [ ] Choose three priorities
   - [ ] Check the calendar
   ```

4. 把任务设置为明天到期。
5. 保存任务。
6. 在检查单区域完成其中一项。
7. 再次保存。
8. 打开历史，确认保存操作已经被记录。

完成这些步骤后，你应该已经熟悉桌面端的主要部分。

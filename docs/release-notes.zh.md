# 发布记录

本文件按版本维护。

请在创建发布提交前更新它，而不是每次本地修改后都更新。每条记录应描述该版本面向用户或项目层面的结果。

## 格式

```text
## <version> - <YYYY-MM-DD>

- 摘要：<一句话说明>
- 变更：<重要实现或文档变更>
- 验证：<发布提交前运行的检查>
```
